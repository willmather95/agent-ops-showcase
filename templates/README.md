# Templates

Blank versions of the files every seat on a team reads at the start of each run. Copy them into a folder per property, fill in the brackets, and point each seat's instructions at that folder.

| File | Purpose |
|---|---|
| `BRIEF.md` | What the property is, the conversion that counts, and what needs the owner's yes |
| `STATE.json` | Current numbers, each with a source and a date |
| `LOG.md` | Append-only record of every action |
| `MISTAKES.md` | Lessons that became rules |
| `FAILURE-CHECKLIST.md` | Likely failures per seat, and the pre-merge checklist |
| `cloudagent-prompt.md` | A builder brief for one draft PR |
